# 💼 Diego Salcedo | Portfolio

A modern developer portfolio built with **Astro** and **Tailwind CSS** to showcase my projects, skills, and journey as a software developer.

This portfolio was designed with a focus on performance, clean UI, and maintainable code while learning modern frontend technologies.

---

## ✨ Features

- 👋 Personal introduction
- 💼 Project showcase
- 🌌 Interactive particle background built with HTML Canvas
- 📱 Fully responsive design
- ⚡ Optimized with Astro
- 🎨 Modern UI using Tailwind CSS
- 🚀 Deployed on Vercel

> Planned features:
>
> - 🌙 Enhanced animations
> - 📄 Downloadable résumé
> - 🌎 Multi-language support
> - 📝 Blog section

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/portfolio.git
```

Go into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```text
http://localhost:4321
```
